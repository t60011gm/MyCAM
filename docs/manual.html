MyCAM 使用手冊

版本 0.1 ｜ 適用 Windows 10/11 與 macOS 13 以上

MyCAM 是給教師上課錄影、製作教材用的螢幕錄影工具。錄影時可以隨手加「段落」，錄完自動變成有索引的教材，可匯出 MP4、網頁教材、智慧大師（WMPro）教材包，或直接上傳 YouTube。

1. 安裝

Windows

  1. 執行 MyCAM Setup 0.1.0.exe（安裝版）或直接執行 MyCAM 0.1.0.exe（免安裝版）。
  2. 若出現藍色的「Windows 已保護您的電腦」，按「其他資訊」→「仍要執行」。這是因為程式沒有購買數位簽章，不是病毒。
  3. 不需要另外安裝任何軟體，影片轉檔工具已內建。

macOS

  1. 打開 DMG，把 MyCAM 拖到「應用程式」。
  2. 第一次開啟若出現「無法打開，因為 Apple 無法檢查…」：到「系統設定 → 隱私權與安全性」，往下捲按「強制打開」。
  3. 若出現「已損毀」，在「終端機」執行一次：xattr -cr /Applications/MyCAM.app
  4. 第一次錄影時系統會詢問「螢幕與系統音訊錄製」「麥克風」「攝影機」權限，請全部允許。允許螢幕錄製後要完全結束 MyCAM 再重開才會生效。

2. 第一次使用：設定

點左側「⚙ 設定」：

項目 說明
儲存位置 每次錄影會在這裡建立一個資料夾。預設是「影片\MyCAM」。建議選容量大的磁碟。
錄影快捷鍵 錄影中全域有效，即使在放 PowerPoint 也能按。Windows 預設 F8 / F9 / F10，macOS 預設 Control+Option+M / P / S。
繼續錄影時自動新增段落 勾選後，按「暫停」再按「繼續」時會自動在繼續的位置加一個段落。適合「換主題就先暫停」的習慣。預設關閉。
YouTube 上傳 需要填 Google API 的 Client ID / Secret 才能上傳，步驟見第 7 節。不上傳 YouTube 可略過。

3. 錄影

3.1 開始前的設定

點「⏺ 新增錄影」：

  1. 錄製範圍：選整個螢幕，或只錄某個視窗（例如 PowerPoint）。多螢幕時會列出每個螢幕。按「重新整理」可更新縮圖。
  2. 錄影標題：預設是日期，建議改成課程名稱，例如「微積分 第3週 極限」。這會成為資料夾名稱與影片標題。
  3. 聲音
    • 錄製麥克風：講課旁白。可選擇要用哪一支麥克風。
    • 錄製系統聲音：電腦播放的聲音（影片、音樂）。Windows 直接支援；macOS 需 14.2 以上。
  4. 教師攝影機：勾選後會把攝影機畫面疊在角落（子母畫面），可選位置與大小。
  5. 品質：一般上課用預設 30 fps、6 Mbps 即可。只放投影片可選 15 fps，檔案更小。

3.2 錄影中

按「⏺ 開始錄影」後，MyCAM 會縮成螢幕右下角的一條浮動控制列，不會被錄進影片。

控制列由左到右：

元件 功能
紅點 + 時間 已錄時間（暫停時間不計）
「N 段」 目前已加的段落數。出現 ⚠ 表示有裝置問題（例如找不到麥克風），滑鼠移上去可看原因，錄影仍繼續。
段落標題輸入框 可先打段落名稱再按「＋段落」，留白會自動命名「段落 1、2、3…」
＋段落 在目前時間加一個段落節點（快捷鍵 F8）
⏸ / ▶ 暫停／繼續（快捷鍵 F9）。暫停期間不錄，影片會直接接起來。暫停本身不會產生段落；若想「繼續」時自動加段落，到「設定」勾選「繼續錄影時自動新增段落」。
■ 停止並儲存（快捷鍵 F10）
✕ 放棄這段錄影，檔案會刪除

加段落的訣竅：換一個主題、換一個題目、開始一段示範時按一下 F8 就好，標題可以錄完再慢慢改。

3.3 停止之後

按 ■ 後會花幾秒「整理錄影檔」（修正影片長度、產生縮圖），完成後自動進入編輯器。錄一小時大約也只要幾秒。

4. 編輯段落索引

編輯器左邊是影片，右邊是段落清單。

  • 改標題：直接在段落的文字框打字，會自動儲存。
  • 跳到某段：點段落左邊的藍色時間。
  • 調整段落時間：把影片播到正確位置，按該段落的「⌖」，會把段落改到目前播放位置。
  • 新增段落：把影片播到想要的位置，按影片下方「＋ 在 00:00 新增段落」。
  • 刪除段落：按「✕」。
  • 補充說明：會附在 HTML 教材頁和 YouTube 說明欄，可放課程重點、作業、參考資料。
  • 開啟資料夾：右上角「📁」開啟這次錄影的資料夾。

段落會依時間自動排序。第一個段落不在 0 秒時，匯出會自動補一個「開始」段。

5. 匯出

編輯器右側「匯出」區：

項目 產出 用途
MP4（內嵌章節） output.mp4 最通用的影片檔。用 VLC、PotPlayer 等播放器可直接看到章節選單。上傳 YouTube 也用這個檔。
依段落切成多個 MP4 segments\01-xxx.mp4… 每段一個檔，適合分次給學生或放進其他平台。切點精準。
HTML 教材播放頁 index.html 用瀏覽器開的教材頁：影片 + 段落索引側欄 + 縮圖，點段落即跳轉。整個資料夾放到網站、隨身碟或雲端都能用。
章節時間軸文字 chapters.txt 「00:00 開始」格式的文字，貼到 YouTube 說明欄會自動變成章節。「複製」直接進剪貼簿。
智慧大師 / SCORM 1.2 教材包 <標題>-SCORM.zip 見第 6 節。

匯出時會顯示進度條。MP4 匯出通常很快（不需重新編碼）；切段和 SCORM 需重新編碼，一小時課程約需數分鐘。

6. 上傳到旭聯智慧大師（WMPro）

  1. 在編輯器選「智慧大師（WMPro）/ SCORM 1.2 教材包」。畫質建議選「720p 精簡」（檔案小很多，投影片教學畫質仍清楚）。按「產生」。
  2. 完成後會自動開啟資料夾並選取 <標題>-SCORM.zip。
  3. 登入智慧大師，進入課程 →「課程管理」→「教材匯入」。
  4. 選取這個 zip，教材種類選「SCORM 1.2」，學習路徑選「取代目前的路徑」或「附加在後面」，按匯入。
  5. 到「學習路徑管理」查看：每個段落已成為一個節點，另有「課程總覽（連續播放）」節點。學員看完會記錄完成狀態，可在閱讀統計查看。

檔案太大上傳失敗？ 學校平台通常有單檔上限（手冊寫 64 MB）。此時改用 FTP 或 Web 資料夾，把錄影資料夾裡的 scorm\ 整個目錄上傳到課程教材區，再到「學習路徑管理」手動新增節點，分別連到 chapters/01.html、chapters/02.html…（或 index.html 連續播放）。

7. 上傳 YouTube

7.1 一次性設定（約 10 分鐘）

YouTube 規定每個上傳程式要有自己的 API 憑證，請依下列步驟申請（免費）：

  1. 到 Google Cloud Console 用您的 Google 帳號登入，建立一個專案（名稱隨意，例如 MyCAM）。
  2. 「API 和服務」→「程式庫」→ 搜尋「YouTube Data API v3」→ 啟用。
  3. 「OAuth 同意畫面」→ 使用者類型選「外部」→ 填應用程式名稱與您的信箱 → 儲存。在「測試使用者」加入您自己的 Google 帳號。
  4. 「憑證」→「建立憑證」→「OAuth 用戶端 ID」→ 應用程式類型選「電腦版應用程式」→ 建立。
  5. 把畫面上的「用戶端 ID」和「用戶端密鑰」貼到 MyCAM「設定 → YouTube 上傳」，按「儲存」，再按「登入 Google 帳號」。瀏覽器會開啟授權頁，選您的帳號並允許，看到「已完成授權」即可關閉。

7.2 上傳

  1. 編輯器右側「上傳 YouTube」：確認標題，說明欄已自動帶入章節時間軸與補充說明。
  2. 選隱私：「不公開」（有連結才看得到，最適合給學生）、「私人」或「公開」。
  3. 按「⬆ 上傳」，會先自動匯出 MP4（若尚未匯出）再上傳，顯示進度。完成後顯示影片連結。

注意：Google 對未經審核的程式有限制，透過 API 上傳的影片會先被鎖定為「私人」。上傳完到 YouTube Studio 把該影片改成「不公開」或「公開」即可。

8. 錄影資料庫與檔案

左側「📚 錄影資料庫」列出所有錄影，點卡片進入編輯器，可搜尋標題。

每次錄影是一個獨立資料夾，位於「設定」的儲存位置：

2026-09-16-143728-微積分 第3週/
├─ raw.mkv          原始錄影（不要刪，所有匯出都從這裡產生）
├─ project.json     標題、段落索引、補充說明
├─ thumb.jpg        縮圖
├─ output.mp4       匯出的 MP4
├─ index.html       HTML 教材頁
├─ segments/        切段的 MP4
├─ scorm/           智慧大師教材包內容
└─ chapters.txt     章節文字

備份：整個資料夾複製即可，換電腦後把資料夾放回儲存位置就能在資料庫看到。

刪除：資料庫卡片上的「刪除」會刪掉整個資料夾，無法復原。

9. 常見問題

錄出來是黑畫面 macOS：尚未允許「螢幕錄製」權限，或允許後沒有重開 MyCAM。Windows：某些有 DRM 的影片（例如串流平台）本來就無法錄。

沒有聲音

  • 麥克風：設定頁確認有選到正確的麥克風；控制列出現 ⚠ 表示找不到麥克風。
  • 系統聲音：macOS 14.2 以下無法直接錄，可安裝 BlackHole 虛擬音源後選為麥克風。

快捷鍵沒反應 可能與其他軟體衝突，到「設定」改成別的組合（例如 CommandOrControl+Shift+M）。

錄某個視窗時畫面停住 該視窗被最小化或關閉時就錄不到。錄 PowerPoint 建議直接錄整個螢幕。

檔案太大 錄影前把品質改成 15 fps、2.5 Mbps；匯出智慧大師教材包時選「720p 精簡」。

Windows 說這是不明的發行者 程式沒有購買數位簽章憑證，按「其他資訊 → 仍要執行」即可。

macOS 錄到浮動控制列 把控制列拖到不錄的另一個螢幕，或全程用快捷鍵操作。
